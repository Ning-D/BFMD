ドロップダウンで動画を選ぶだけで対応するしきい値が自動適用されます（表に無い動画は demo_petronas 用の既定値）。

| パラメータ | demo_petronas（バドミントン） | tennis_01 | pickleball_01 |

| L2: YOLO conf / N_PLAYERS | 0.4 / 2 | 0.4 / 2 | 0.4 / 2 |
| L2: 推論解像度 imgsz | 640 | 640 | **1280**（奥の選手が小さいため） |
| L2: 追跡器 | botsort（既定） | botsort（既定） | **ByteTrack調整版**（track_buffer=90, high_thresh=0.3, new_track=0.4） |
| merge_parts（色領域の結合数） | 1 | 1 | **2**（センターラインで左右分断されるため） |
| 競技 / コート実寸 | badminton 6.10×13.40m | tennis 10.97×23.77m | pickleball 6.10×13.41m |
| 検出4隅の対応矩形 quad_dst | (0, 6.70)〜(6.10, 13.40) 手前ハーフ | **(0, 0)〜(10.97, 23.77) コート全面** | **(0, 0)〜(6.10, 13.41) コート全面** |

**pickleball の追加設定について**: 奥の選手は 640px 推論では検出が途切れ、ID が細切れになる
（実測: 既定設定だと奥の選手は 70% のフレームでしか追跡されない → imgsz=1280 + 追跡器調整で 93% に改善）。
プリセットセルが `preset_tracker.yaml` を自動生成するので手作業は不要。

**erode が負の理由**: ピックルボール・テニスとも、外周ライン（ベースライン等）がコート色領域の
「境界上」にあるため、領域を内側へ収縮させると外周の白線がマスクから消えてしまう
（テニスでは細い外周線が落ち、内側のサービスラインで4隅が組まれてしまう）。
負の値で外側へ広げて境界の白線を含める。

## L3 パイプラインに入れた修正（全動画共通・バドミントンの結果は修正前と同一）

1. **白線ブリッジ**: コート色マスクを連結成分分析の前に 9px 膨張。
   白線でコートが複数の連結成分に分断される問題を解消。
2. **中央優先の領域選択**: 「最大の連結成分」ではなく「画面中央付近にある十分大きい成分」を優先。
   広告板・観客席の誤選択を防ぐ。
3. **上位N領域の結合（merge_parts）**: ピックルボールはセンターラインでコートが左右2つの
   成分に分かれるため、上位2成分を結合してから輪郭を取る。
4. **奥ベースライン検出（far_top）**: ピックルボールはネット帯で奥コートの色領域が分断される。
   奥側の領域を別途拾ってその最上端の横線（奥ベースライン）を上辺に採用し、
   サイドライン（平面上の直線）を延長して交点を取ることで**コート全面の4隅**を得る。
   実測: 全面4隅のドリフト15px、両選手とも4隅の内側に正しく投影。
   （demo_petronas での検出4隅は修正前とほぼ同一: [383,348][891,348][1036,674][237,674] ≒ ノート内の手動参考値）

## 4隅→コート全面図への投影（quad_dst）と競技別 2D 図

- テニス・ピックルボールは**コート全面の最外郭**（両ベースライン×最外サイドライン）を検出。
  バドミントン demo は従来どおり手前ハーフ（ネット〜手前ベースライン）が基準矩形。
  検出4隅がコート全面のどの矩形に当たるかはプリセットの `quad_dst` に記録される。
- ホモグラフィは**平面全体で有効**なので、4隅の外側にいる選手も正しくコート全面図に投影される
  （検証済み: テニスの手前側選手 → 手前半面 19.3m 地点に正しく投影）。
  これは同時に、旧ノートの「手前ハーフの4隅を全面にマップして縦が2倍に伸びる」バグの修正でもある。
- **標準コートの 2D 図**と投影背景は `PRESET_SPORT` で自動切替:
  badminton（BWF 公式線・緑）/ tennis（ITF 公式線・青）/ pickleball（USAP 公式線・青、キッチンライン付き）

## 不採用としたもの（テスト結果の要約）

- **バドミントン追加クリップ**: demo_petronas がバドミントンなので不要（badminton_01/03 は両テスト通過していたが削除）
- **ダブルス各種**: 4人分の ID が安定せず追跡カバー率 10〜58%
- **tennis_03（全豪）**: 全面青コートでマスクが画面全体に広がり、外枠の誤検出
- **卓球（全5本+追加候補3本）**: ①選手が台や画面端で隠れ ID が細切れ（カバー率 0〜60%）、
  ②ハイライト動画は10秒前後でカメラが切り替わり追跡が途切れる、
  ③白線が細く Hough で拾えない（台面は輪郭検出なら可能だった: navy V∈[80,160] + approxPolyDP）。
  → **今回はスキップ**。再挑戦するなら「固定高所カメラ・ノーカット・選手全身が写る」素材が必要

## 再ダウンロード方法

```bash
yt-dlp --cookies ../www.youtube.com_cookies.txt --no-playlist \
  --download-sections "*START-END" --force-keyframes-at-cuts \
  -S "res:720,ext:mp4:m4a" --merge-output-format mp4 \
  -o out.mp4 "https://www.youtube.com/watch?v=ID"
# tennis_01:     ID=-jtV7IJP8NU  START=25  (14s)
# pickleball_01: ID=fJJxoKbU4ic  START=185 (14s)
# pickleball_02: ID=fJJxoKbU4ic  START=230 (14s) ※01と同じ試合の別ラリー
```

（Drive には `MyDrive/video-clips` としてアップロードしてください。L2 が生成する追跡JSONは
`MyDrive/video-clips/tracks/<動画名>_player_tracks.json` に保存され、L3 が自動で読み込みます）
